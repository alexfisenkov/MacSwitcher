# 0.1.0-alpha.7 — исправление запуска перехватчика

Живой прогон alpha.6 отказал до начала редактирования: новый fence уже был
инвалидирован уведомлением tapDisabledByUserInput. Причина подтверждена
сравнением одного изменения: после создания event tap код вызывал
tapEnable(false), затем включал его снова. Лишний начальный вызов удалён.

Добавлен пробник `--self-test-event-tap-host`, который не открывает окна,
не запрашивает права, не отправляет события и не сохраняет клавиши. За две
секунды он проверяет валидность/включённость tap и считает только callbacks,
уведомления отключения и исполнение callback на main.

Локальный baseline: ready/valid/enabled=true, один disabledUserInput.
После удаления только начального отключения: ready/valid/enabled=true,
ноль отключений и callback на main. Это проверка жизненного цикла,
не физическая приёмка клавиатуры или редакторского преобразования.

Все 286 Swift-тестов, 16 Python-тестов и 495 словарных регрессий прошли.
Словари и окно двойного Shift 180 мс сохранены из предыдущего кандидата.
Обычный native rollout остаётся закрыт через UI до принятого выпуска;
на установке владельца сохранено исключение Codex.

Сравнительный a57d597 собран из чистого публичного SHA, подписан Developer ID
и подготовлен к установке. Установленная 6512f31 дала описанные ниже отказы;
живой прогон a57d597 и финальная CI ещё не выполнены. Alpha.5 и настройки
сохранены для отката; прежние результаты не объявляются приёмкой alpha.7.

Дополнительно исправлена защитная проверка тестового executable: Foundation
вернул /tmp, тогда как драйвер сравнивал нормализованный URL с сырым
/private/tmp. Теперь обе стороны нормализуются одинаково; другой executable
по-прежнему отклоняется. Добавлены регрессии alias/symlink/пробелов и emoji.
До исправления guard отказал с нулём отправленных событий.

Повторный запуск тестового драйвера выявил отдельный аварийный вызов
TISGetInputSourceProperty с фонового потока (HIToolbox queue assertion).
Все TIS-запросы и Unicode-перевод драйвера перенесены на Main; worker получает
только свежие строковые Sendable-снимки. Фоновый и Main-вызовы покрыты
реальными регрессиями без UI и отправки событий. После таймаута UI-проверки
сначала проверяется процесс/отчёт аварии: наблюдение CUA может перезапустить
приложение без диагностических аргументов и скрыть факт завершения.

Редакторский прогон дошёл до ввода ghbdtn и словарного предложения, но native
запись была отклонена до отправки пары: стандартный NSTextView не публикует
AXEnabled/AXEditable. Поддержка определяется положительной способностью
замены AXSelectedText, если необязательные флаги отсутствуют. Живой readonly
переключатель показал SelectedText setter=false; такое поле пропускается.
Явные запреты, ошибки AX и неверные Boolean не считаются отсутствием.
В CLI добавлены только состояния этих флагов, без содержимого редактора.

Активация отдельного fixture теперь отложена на 300 мс после нажатия кнопки
теста. Проверки PID/path/focus сохранены; отмена до старта не активирует окно.
Это стабилизация тестового окружения, не задержка обычного ввода или Shift.
Фактический эффект проверяется отдельным живым прогоном.

Повторный прогон остановился с focusLost до отправки первого события.
Драйвер теперь сообщает первую причину: идентичность fixture, foreground PID,
отсутствующее переднее окно, его владелец или идентичность. В отчёт попадает
только категория, без PID, заголовков окон или текста. Проверки не ослаблены.
Причина повторной потери фокуса и обычная работа редакторов ещё проверяются.

Перед фиксацией тестового окна теперь требуется 100 мс неизменных PID/ID;
проверки во время отправки остаются прежними. Живой прогон выявил отдельный
отказ подтверждения: выделение визуально заменяется, но AX focus с таймаутом
3 мс недоступен до общего срока. При быстром наборе шестибуквенного слова
серия остановилась после части удалений; исходник удержан для восстановления.
Эти сценарии не приняты. Обычное автопереключение Codex не включено.

Для сравнения добавлен диагностический выбор AX-таймаута 1/3/10/20 мс.
Он требует оба флага тестового процесса; обычный запуск остаётся на 3 мс.
Каждый запрос ограничивается оставшимся сроком, отказ установки таймаута
останавливает чтение. В отдельном fixture можно объединять только перерисовку
счётчика (`--coalesce-counter-display`), сохраняя точный счёт и порядок событий.
Результаты сравнения фиксируются после подписанной сборки.

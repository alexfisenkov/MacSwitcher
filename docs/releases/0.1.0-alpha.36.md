# MacSwitcher 0.1.0-alpha.36 · повторное исправление после задержки

Кандидат исправляет один из случаев, когда после замены переставал действовать двойной Shift. Если редактор поздно подтвердил вставленный текст, следующая быстрая пара проверяет результат и может вернуть исходное слово без обязательного выделения всего поля. После подтверждённого возврата обычная работа продолжается.

Настройки Shift, словари и интерфейс не меняются. Если результат неизвестен или поле уже изменилось, исходник сохраняется, а повторная запись остаётся запрещённой. Совместимость со всеми редакторами не заявляется: причина первоначального несовпадения в браузере пока не установлена.

Локальная проверка кода: 773 Swift-теста, ноль ошибок и один условный пропуск; 54 Python-проверки. Проверены поздний результат, старое значение AX, повторные отмена/возврат, следующее слово, подмена полного поля перед записью и сохранение первого исходника при повторной неопределённости. Синтетические сценарии не заменяют проверку физической клавиатуры в браузере.

Контракт и границы проверки — в [плане](../plans/2026-11-18-late-ack-recovery.md). Публичный выпуск и живая приёмка учитываются отдельно.

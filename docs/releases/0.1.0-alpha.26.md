# MacSwitcher 0.1.0-alpha.26 — кандидат

Настройки получили боковую навигацию по прежним шести разделам. Длинные формы прокручиваются, размер окна ограничивается экраном. Сохранены обработчики, ключи настроек, ручной словарь, обучение и тайминги Shift.

В локальной диагностике устранена потеря повторных причин отказа: раньше большинство событий автокоррекции выводилось один раз за весь запуск. Теперь отдельные причины отказа повторно доступны не чаще одного раза в пять секунд на причину. Это работает только при включённой диагностике; текст, клавиши, clipboard и значения полей в неё не поступают. Успешные частые этапы по-прежнему не засоряют журнал.

Добавлены проверки продолжения автокоррекции после ручной замены русского слова на английский бренд и после потери якоря с переходом к следующему слову, а также после неподтверждённой замены и точного восстановления выделением на том же координаторе. Эти сценарии прошли, но сообщённый пользователем прерывистый отказ целиком не воспроизведён. Исправление исходного симптома не заявляется. Защиты неподтверждённого текста, поля и раскладки не ослаблены.

Состояние выпуска, подпись, итоговая CI, установка и визуальная проверка интерфейса фиксируются отдельно после выполнения. Windows в этом кандидате не меняется.

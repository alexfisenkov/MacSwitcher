# MacSwitcher 0.1.0-alpha.29

Проверяемое восстановление ручной конверсии при устаревшей истории набора.
Двойной Shift может быть правильно распознан, но буферное слово уже не
совпадать с текстом у курсора. Раньше непустой буфер не позволял перейти к
проверяемой конверсии фактического последнего слова.

Теперь длина буферного суффикса сравнивается с исходной позицией курсора
до записи. Когда история длиннее доступного префикса, разрешён
существующий путь последнего слова с тем же полем, исходной кареткой, ревизией,
раскладкой и точным повторным чтением ограниченного поля. После неоднозначной
записи другой способ не запускается.
Обычный словный маршрут не получает дополнительных AX-запросов.
Несовпадение буфера допустимой длины этим восстановлением не обрабатывается.

Диагностика отдельно различает недоступную начальную каретку,
неколлапсированный диапазон и слишком короткую позицию относительно буфера.
Это закрытые коды без набранного текста, координат и клавиш.

Тайминги одиночного и двойного Shift, выделение, undo/redo, автокоррекция,
личные словари и обучение этим выпуском не перенастраиваются.

Исходная диагностика alpha.28 локализовала отказ до проверки каретки, но не
различала перечисленные варианты. Прохождение синтетической регрессии
устаревшего буфера не доказывает устранение всех возможных отказов AX в чужих
редакторах. Исходный live-отказ пока не считается закрытым.
Физическая проверка установленной версии учитывается отдельно.

# 0.1.0-alpha.5: повторное чтение native-фокуса

В единственном физическом опыте alpha.4 владелец увидел правильное `прив`
в Codex, но транзакция вернула UNKNOWN после недоступного AX-фокуса. Она
завершилась примерно через 28 мс после вставки, раньше общего лимита 100 мс.
Точная ошибка AX тогда не записывалась; таймаут не считается доказанной причиной.

Alpha.5 повторяет только неудачный захват фокуса (`focusUnavailable`) в оставшемся
прежнем бюджете. Причины AX уточняют диагностику; они не доказывают временность отказа.
Проверки исходного поля, PID, revision, secure input и поколения tap сохранены.
Обнаруженная смена поля/PID/revision, secure input или потеря gate прерывают
операцию. Во время повторного чтения после `focusUnavailable` новые клавиатурные
события не отправляются; повторной вставки, удаления или нового способа записи нет.
Диагностика пишет только статические причины ошибок AX, без текста и клавиш.

Обычная автокоррекция Codex остаётся заблокированной. One-shot canary по-прежнему
требует обоих флагов, отдельной кнопки на 30 секунд, US и всего поля `ghbd`.
Проверка общего native-режима, поздней доставки и конкурентного ввода не закрыта.
Жесты Shift и поддержанные пути TextEdit не заменялись.

## Проверка

- 141 тест на Swift PASS, включая 12 регрессий bounded revalidation и прохождение
  всей транзакции после временной недоступности без повторной мутации.
- 6 Python-тестов, public validator (89 файлов), hashes словарей и diff check PASS.
- Критик поведения кода: WARN по видимости повторной AX-ошибки → PASS после
  исправления границы дедупликации. Скептик: общая поддержка Codex остаётся
  незавершённой; кандидат не объявляет её реализованной.
- Одна финальная [GitHub CI](https://github.com/alexfisenkov/MacSwitcher/actions/runs/39573132766)
  на `b47072968fabc34756920b1631094d01dca6d48d` — SUCCESS: 141 Swift / 6 Python,
  public89 и упакованные словари по 200 000 RU/EN.
- Developer ID bundle того же source pin установлен, SourceDirty=false,
  strict signature проверена; предыдущая сборка сохранена для отката.
- Один физический Codex-canary на установленной alpha.5 — PASS: журнал содержит
  `nativeAutoVerified`, `autoEditPosted`, `sourceNotificationPreserved`;
  владелец подтвердил `прив` и русскую раскладку после ручного `ghbd` без пробела.
  Повторное чтение фокуса в этой попытке не понадобилось; механизм retry
  доказан регрессиями, а прежний AX-отказ в этом прогоне не повторился.
- После опыта восстановлен обычный режим без диагностической панели и canary.
  Общее исправление Codex остаётся выключенным: быстрый непрерывный ввод,
  поздняя доставка и смена поля не прошли приёмку.

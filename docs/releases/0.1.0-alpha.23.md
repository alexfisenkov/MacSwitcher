# MacSwitcher alpha.23 — кандидат

Исправлен воспроизведённый дефект восстановления автокоррекции: единичный отказ первого захвата поля больше не оставляет последующие слова в том же сеансе без исходной привязки. Неудачное слово остаётся нетронутым; после пробела следующее слово получает новый сеанс и новый захват поля. Повторного захвата в середине неудачного слова нет.

Подготовка доступности Electron отделена от визуального флажка у курсора. Запрашивается только служебный AXManualAccessibility у текущего приложения при запуске включённого мониторинга и активации приложения; текст и фокус не изменяются. Пароли, Secure Input, неподтверждённые поля и исходные проверки записи сохраняют прежние ограничения. Интервал двойного Shift остаётся 180 мс, словари и пользовательские настройки не меняются.

После временного отказа подготовка повторяется на существующем двухсекундном тике. Общий выключатель MacSwitcher останавливает подготовку; исключения автокоррекции сохраняют ручную команду.

Диагностика отказов выделения и последнего слова разделена на закрытые коды этапов. Повторные отказы видны при уже включённой диагностике; содержимое текста, клавиш и буфера обмена в журнал не попадает.

Исходный пользовательский сбой произошёл в Claude. При live-инвентаризации сначала наблюдался недоступный фокус, затем после запроса служебной доступности — AXTextArea с доступными значением и диапазоном. Между измерениями изменилось активное приложение, поэтому это не изолированный эксперимент и не доказательство полного исправления Claude. Словарные проверки подтвердили преобразования nfr → так, b → и, j,sxyj → обычно на границе слова; режим владельца «Конвертировать по тексту» преобразует всю фразу.

Синтетическая production-проверка дополнительно проходит отказ автоматического захвата → ручное исправление → отмену → повтор → исправление следующего слова с подтверждением текста, раскладки и освобождения допуска после каждого шага. Она не отправляет физические Shift.

Локальный общий прогон прошёл: 471 Swift-тест без ошибок, 495/495 примеров неизменённого gold-корпуса, проверка публичных данных и whitespace. Шесть независимых линз критики проверили поведение кода, риски, практический путь, зависимости, секреты и соответствие заданию. Финальные CI, подписанная сборка, выпуск, установка и физическая проверка этого кандидата пока не подтверждены. Прежние результаты alpha.22 не заменяют проверку alpha.23. Полная совместимость приложений и причина всех ручных отказов остаются открытыми.

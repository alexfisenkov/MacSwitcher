# MacSwitcher 0.1.0-alpha.33 · кандидат на физическую проверку

## Цель кандидата

После подтверждённого владельцем случая, когда в Codex не сработала автоматическая коррекция, проверяется один узкий участок: подготовка активного приложения к получению системной информации о поле ввода.

В alpha.33 общая подготовка больше не зависит от буквального имени `Electron Framework.framework`: на активации и штатном опросе приложение читает стандартную роль активного приложения, не извлекая содержимое поля. Существующий Electron-specific setter сохранён только для ранее поддерживаемой Electron-структуры. Успешное чтение роли означает лишь, что запрос завершился; оно не подтверждает доступность активного поля и не гарантирует доставку текста.

Фокус, проверка PID/поля/revision/caret, безопасная запись, Shift, словари и проверка результата не изменены. Наличие успешных коррекций в том же сеансе не устанавливает причину отдельного пропуска. Исправление конкретной жалобы в Codex пока не доказано.

# MacSwitcher alpha.17 — кандидат

Статус: исходники и проверки подготовлены; подписанный архив, нотариальное подтверждение, GitHub release и штатное обновление ещё не выпущены и не установлены.

- Проверка защищённого поля выполняется до чтения выделения или всего текста. Ошибка ответа AX приводит к отказу.
- История набранных клавиш ограничена. Длинное слово или строка не исправляются по усечённому фрагменту; после пробела можно начать новое слово.
- Предиктивный буфер ограничен по UTF-16, включая последовательности составных символов.
- При неизвестном результате сообщение не обещает сохранённую копию исходника, если её нет.
- Слишком большой файл личного словаря сохраняется без изменений и показывает причину отказа.
- Сборщик отклоняет вывод внутри Applications и пути через символьные ссылки.

Локально прошли 424 Swift-теста, 26 Python-проверок, Release arm64 и неизменённый корпус из 495 языковых примеров. Полный набор Swift-тестов под AddressSanitizer прошёл без сообщений об ошибках; адресный набор из 52 тестов под ThreadSanitizer также прошёл. Покрытие строк production-кода в headless suite — 39,52%; подробные пределы приведены в [отчёте об устойчивости](../testing-hardening.md).

До публикации нужны проверка чистого коммита, финальная CI, подпись, notarization, проверка архива и штатного обновления. Физический ввод на клавиатуре и поведение в пользовательских редакторах пока не проверены; этот кандидат не объявляет все приложения принятыми.

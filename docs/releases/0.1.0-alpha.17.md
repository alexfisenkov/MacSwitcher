# MacSwitcher alpha.17

[Предварительный выпуск опубликован](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.17) и установлен на одном Mac штатным Sparkle-обновлением alpha.16 → alpha.17.

- Проверка защищённого поля выполняется до чтения выделения или всего текста. Ошибка ответа AX приводит к отказу.
- История набранных клавиш ограничена. Длинное слово или строка не исправляются по усечённому фрагменту; после пробела можно начать новое слово.
- Предиктивный буфер ограничен по UTF-16, включая последовательности составных символов.
- При неизвестном результате сообщение не обещает сохранённую копию исходника, если её нет.
- Слишком большой файл личного словаря сохраняется без изменений и показывает причину отказа.
- Сборщик отклоняет вывод внутри Applications и пути через символьные ссылки.

Исходный коммит: `fa297ddd95e584bc61658ba0c97664888fbddfc5`.
SHA-256 опубликованного ZIP (23 948 006 байт): `1cb031652706734a516c5fa79536fa6b7a2e832ae39bd51feb0d674d1fdaa1cb`.

[Финальная CI 40691640511](https://github.com/alexfisenkov/MacSwitcher/actions/runs/40691640511) успешна: 424 Swift-теста, 27 Python-проверок и неизменённый корпус из 495 языковых примеров. Проверка из чистого клона прошла. Полный набор Swift-тестов под AddressSanitizer прошёл без сообщений об ошибках; адресный набор из 52 тестов под ThreadSanitizer также прошёл. Покрытие строк production-кода в headless suite — 39,52%; подробные пределы приведены в [отчёте об устойчивости](../testing-hardening.md).

Универсальный архив arm64/x86_64 подписан Developer ID, принят Apple (notarization `191cb001-0325-4dda-820b-23315b5deb70`), снабжён нотариальной квитанцией и принят Gatekeeper. Опубликованный ZIP, подписанный канал обновлений и установленный бинарник независимо перечитаны и совпали с проверенным кандидатом. Приложение запущено; 20 контролируемых настроек не изменились. Файл личного словаря отсутствовал до и после, поэтому сохранность существующего файла этим обновлением не проверена.

Владелец сейчас проверяет физический ввод в Telegram; результат ещё не получен. Длительная работа, быстрый набор и совместимость со всеми редакторами остаются открытыми. Синтетические тесты, подпись и установка этих проверок не заменяют.

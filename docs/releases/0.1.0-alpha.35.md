# MacSwitcher 0.1.0-alpha.35 · редактируемые многострочные поля

Двойной Shift мог распознаваться, но отказываться исправлять выделенное слово в редакторе промпта. В некоторых полях перенос абзаца присутствует в полном значении поля, но отсутствует в тексте, по которому системный интерфейс считает позиции выделения. Старая версия проверяла выделение как срез полного значения по этому числу. После переноса оно могло указывать на другую букву.

Кандидат сопоставляет полное форматированное значение с текстом всего того же элемента в координатах выделения. Слово ищется по проверенной позиции, а не по первому совпадению. Неподтверждённая позиция остаётся основанием для отказа. Слово без выделения можно исправить у проверенной каретки перед разделителем; исходный текст справа должен остаться прежним. Интервал двойного Shift и словари не меняются.

Диагностика различает официальное приложение Claude, отдельно настроенный локальный экземпляр и стабильный VS Code. Эти названия помогают читать журнал; они не выбирают способ исправления и не отправляют имена пользовательских приложений в сеть. Для остальных приложений используются те же правила проверки поля.

Это кандидат для проверки. Поддержка правки уже отправленных сообщений, вывода терминала, защищённых полей и всех возможных редакторов не заявляется. Подробности и границы — в [плане проверки](../plans/2026-11-16-rich-editor-selection.md).

Локальные проверки: 765 Swift-тестов, ноль ошибок, один условный пропуск экспорта изображений; release-сборка прошла. В контролируемых сценариях проверены выделенная фраза в конце черновика, целый внутренний абзац при наличии маркерного подтверждения, выбор правильного повтора, обратное преобразование, полное сохранение текста при смене поля и отказ до записи при несовпадении. Python — 54 проверки, включая схему локального журнала. Непроверяемая позиция, смена адресата или истечение допуска по-прежнему останавливают правку.

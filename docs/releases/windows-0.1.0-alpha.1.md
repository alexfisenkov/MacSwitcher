# MacSwitcher Windows 0.1.0-alpha.1

[Скачать установщик и portable](https://github.com/alexfisenkov/MacSwitcher/releases/tag/windows-v0.1.0-alpha.1). Канал Windows обновлений: `windows/updates/windows.json`.

Первая предварительная версия MacSwitcher для Windows.

- Короткий левый или правый Shift меняет RU/EN. Два быстрых нажатия (180 мс по умолчанию) исправляют последнее слово или выделение; повторный жест отменяет и возвращает замену.
- Ранняя офлайн-коррекция, русский приоритет, личные слова, фразы-исключения и принудительные замены. Набранный текст не отправляется в сеть и не сохраняется в историю.
- 5 198 408 полных и нормативных словарных записей плюс 470 дополнительных защищённых написаний; источники и лицензии включены в пакет.

Скачайте Setup.exe из Assets и запустите. Для portable распакуйте ZIP целиком и откройте MacSwitcher.Windows.exe; папка data должна оставаться рядом. Обычным редакторам права администратора не нужны. Для редактора, уже запущенного администратором, потребуется такой же явный запуск MacSwitcher. Пароли, экран UAC, блокировка и другие пользовательские сеансы пропускаются.

Целевые ОС: Windows 7 SP1, 8.1, 10 и 11, Intel/AMD x86/x64, .NET Framework 4.6.2 или новее. XP, Vista и Windows 8.0 не входят; ARM64 не проверен. Поддерживаются стандартные English US QWERTY и Russian ЙЦУКЕН.

[Windows CI](https://github.com/alexfisenkov/MacSwitcher/actions/runs/41618728418) прошёл на исходнике 7892dc51b8b80cb7628f272da436fce1b58ff875: 562 Core-проверки, включая 495/495 общих gold-примеров, 44 runtime-проверки, собственные WinForms и Edge input/textarea, установка/переустановка/удаление с сохранением данных, первый запуск, повторное открытие настроек и штатный выход. В production-пути собственных Edge-полей UIA-запись заняла 31 и 16 мс при прежнем бюджете 90 мс; DOM независимо подтвердил значение и событие input.

Это alpha для живой проверки. Synthetic adapter не доказывает физическую клавиатуру; реальная матрица Windows, сторонних редакторов, DPI и ARM ещё не пройдена. Поле должно давать безопасный writer и точный read-back; generic UIA middle-selection без native range writer не поддерживается. Поле ограничено 32768 UTF-16 единицами, ручной диапазон и replacement — 4096, отдельное слово — 192. Пробелы, tab и CRLF после слова сохраняются вместе с кареткой. Форматированный rich-text отдельно не сертифицирован.

EXE и Setup пока не имеют Windows Authenticode-подписи издателя. Не отключайте защиту Windows. RSA-подпись собственного update manifest проверяет целостность обновления и не заменяет подпись издателя Windows. При неопределённом исходе отправленного вызова Windows возможно позднее завершение; программа сохраняет исходник в ограниченной RAM и запрещает повтор записи. При аварийном завершении до явного экспорта такая RAM-копия может потеряться.

# MacSwitcher 0.1.0-alpha.32 · локальный кандидат

**Статус на 13 ноября 2026 года:** версия и локальные release-метаданные подготовлены. Alpha.32 не опубликована, не подписана, не нотарифицирована и не установлена. Публичная версия Mac по-прежнему alpha.31; Windows — alpha.3. Ссылки на alpha.32 в локальном `website/index.html` подготовлены для будущей поставки и не подтверждают обновление Pages.

## Что меняется

- Компактное нативное окно AppKit с тремя вкладками; при открытии видна короткая инструкция. Первый Shift переключает раскладку, два быстрых Shift исправляют слово или выделение с учётом сохранённого режима всей строки. Повторная пара отменяет исправление, пока текст, курсор и поле не изменились.
- Единый Shift применяется ко всем профилям после проверенного резервного копирования прежних настроек жестов. Исходные пользовательские значения остаются нетронутыми; резервная копия нужна для безопасного восстановления.
- Автоматическая коррекция текста и фоновое переключение per-app имеют отдельные состояния. Автоматическая коррекция не является условием ручного Shift.
- Слова, фразы, исключения и управление локальным обучением остаются доступны в существующих редакторах.
- Строка меню сохраняет пять обычных действий; операторские и восстановительные пункты показываются по условию и остаются доступны.

- Изолированный Swift-набор: 695 тестов, 0 отказов, один намеренно пропущенный тест экспорта PNG без заданного каталога. Отдельный offscreen-экспорт десяти PNG прошёл.
- Release-сборка прошла; остался ранее существовавший warning о приведении `AXUIElement`.
- `script/check_public.py` прошёл: 327 файлов после добавления этих release-заметок.
- Два раунда независимой проверки завершены. Второй функциональный раунд — PASS; ограничение чтения резервной копии исправлено bounded read до 128 KiB с проверкой файла и дескриптора, целевые и полные тесты повторены. Третий раунд не запускался.
- Метаданные сборки основаны на текущем source tree; frozen commit и SHA-256 пакета ещё не назначены.

Эти проверки не подтверждают работу с реальными пользовательскими данными или настройками, совместимость со всеми приложениями, отображение живого окна, физическое поведение клавиатуры, подписанную сборку, установку или публикацию.

# MacSwitcher 0.1.0-alpha.25

[Скачать universal ZIP](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.25).

Локальное обучение на подтверждённых исправлениях. После двух независимых случаев с одним словом MacSwitcher запоминает выбранную раскладку на этом компьютере. Повторный undo/redo не добавляет подтверждения; обратный выбор снимает правило.

Функция включена по умолчанию с пояснением при первом запуске. В настройках «Обучение» можно выключить её, посмотреть кандидатов и выученные слова, удалить отдельное правило или сбросить всё. Ручной словарь остаётся отдельным.

Файл adaptive-rules.json содержит только пары слов, выбранный вариант и счётчики. История набора, клавиши, фразы, clipboard и данные приложений не сохраняются и не отправляются в сеть. Обучение использует подтверждённые действия, а не считает обычный набор или автоматическое исправление доказательством согласия. Данные остаются отдельными на каждом устройстве.

Технические строки и явные пользовательские правила сохраняют приоритет. Повреждённый файл не затирается; обучение отключается, базовый switcher продолжает работать. Диск обслуживается отдельно от обработки клавиш. Это персональные правила раскладки, а не произвольная орфографическая модель.

Исходник: 58a529f0dcff6aa3cde5439f028d257ee023420a. Физическая клавиатура и пользовательские редакторы остаются отдельной живой приёмкой; synthetic CI не является гарантией работы во всех приложениях.

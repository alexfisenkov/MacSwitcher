# MacSwitcher 0.1.0-alpha.27

Исправление визуально обнаруженного дефекта alpha.26: короткие разделы настроек начинались слишком низко в области прокрутки. Новый контейнер прижимает содержимое к верхнему краю, сохраняя прежнюю геометрию элементов и прокрутку длинных форм. Значения настроек и обработка ввода не меняются.

Сохраняются новая боковая навигация alpha.26, исправленная локальная диагностика повторных отказов и дополнительные проверки продолжения автокоррекции. Общая причина пользовательского прерывистого отказа по-прежнему не установлена; исправление этого симптома не заявляется.

Дополнительный прогон CI нужен из-за конкретного дефекта, выявленного в установленной alpha.26 после успешных тестов, а не для повторения уже пройденной проверки без изменений. Фактическая проверка геометрии и установленного интерфейса фиксируется отдельно.

Геометрические регрессии сначала воспроизвели дефекты: верхний отступ 428/508 pt и пустую прокрутку 280 pt при уменьшении окна. После исправления верхний отступ не превышает 30 pt, короткая форма не прокручивается по пустому месту при уменьшении viewport до 320 pt, последний элемент длинной формы доступен. Оба независимых разбора завершились PASS после принятого замечания о лишней высоте документа. Локально прошли 512 Swift-тестов; итоговая CI и установленный интерфейс проверяются отдельно.

# MacSwitcher 0.1.0-alpha.15 — повторный двойной Shift и коррекция текста

[Публичный предварительный выпуск](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.15)
для macOS 13+. Универсальный пакет поддерживает arm64 и x86_64.

## Что изменилось

- Исправлено повторное использование двойного Shift после предыдущей правки: можно продолжить набор, снова исправить слово или обработать выделенный текст.
- Уточнена ранняя коррекция коротких русских слов во время набора. Ненужное исправление можно отменить; после подтверждённой отмены автозамены приложение предложит добавить исходную фразу в исключения.
- Заводской список приложений, исключённых из автокоррекции, теперь пуст. Ранее добавленные пользователем исключения сохраняются.
- Уведомления об отказе изменить или восстановить текст стали понятнее.
- Парольные поля пропускаются. Если безопасно проверить конкретное поле не удаётся, приложение откажется от изменения. Совместимость зависит от редактора.

## Установка и оставшиеся проверки

Штатное обновление alpha.14 → alpha.15 через Sparkle завершено; проверка
установленного приложения подтвердила соответствие исходному коммиту, подписи,
нотариальной квитанции и Gatekeeper. Настройки сохранены.

Физический ввод с клавиатуры и совместимость со всеми редакторами ещё не
проверены. Headless-проверка event tap подтверждает только доступность и
состояние готовности, но не физические события клавиатуры.
`native_backend_accepted` остаётся `false`.

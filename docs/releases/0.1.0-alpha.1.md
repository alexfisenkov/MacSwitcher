# 0.1.0-alpha.1: что проверено

Это публичная **исходная alpha**, а не стабильный бинарный выпуск.
Код закреплён tag `v0.1.0-alpha.1`, commit
`ca0cc3ad3bf7d08e6c0147b7aceb439d08ff7ce2`.
Последующие изменения этого документа не меняют код и артефакт alpha.

2026-10-21 проверены:

- Локальные 71 Swift-тест и 6 Python-тестов — PASS.
- Один финальный [GitHub Actions run](https://github.com/alexfisenkov/MacSwitcher/actions/runs/39453779299)
  на том же SHA: 71 Swift, 6 Python, сборка и ресурсы — PASS.
- В ARM64 `.app` есть оба словаря по 200 000 записей и лицензии.
  Resource self-test ищет их внутри bundle без исходного дерева.
- Локальный bundle подписан Developer ID; strict-проверка пройдена,
  `SourceDirty=false`, source SHA соответствует pin выше.
- Публичный состав репозитория, хеши словарей и скан секретов проверены.
  Частные настройки, тексты и резервные копии не опубликованы.

**Не проверено:** физический HID-ввод, живые AX-поля редакторов,
новые разрешения macOS и длительная пользовательская приёмка.
Notarization не выполнена: профиль credentials недоступен на текущем Mac.
Поэтому бинарный установщик в публичный релиз не загружен. Исходники
можно собрать по README; чужие автоматические обновления отключены в коде.

Раннее исправление, контекстная `f`, реальные карты раскладок и Shift-жесты
подтверждены регрессионными тестами, не физическим вводом. Обобщать это
на безошибочное понимание любой фразы нельзя. Открытые ограничения и следующая
работа перечислены в [roadmap](../roadmap.md).

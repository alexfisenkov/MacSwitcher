# MacSwitcher Windows 0.1.0-alpha.3 — кандидат

Общая с macOS политика русского контекста после английских названий. Название сохраняется, а следующее короткое русское слово получает русский приоритет. Частотные английские омонимы, обычная английская фраза, технические строки и пользовательские правила сохраняют свои проверки. В базу названий добавлен iPhone.

После подтверждённой отмены автоматического исправления текущее слово не исправляется повторно, следующие слова продолжают обрабатываться. Учтены уже закрытое слово, несколько пробелов и обычная капитализация Shift+буква. Состояние отмены ограничено оперативной памятью, точным полем, префиксом и кареткой; новые журналы текста или настройки не добавлялись.

Локально Core769/gold495 и net462 app/runtime-fixture build PASS. Synthetic runtime contract checks подготовлены, но на Mac не исполнялись; Windows CI, упаковка и публичный read-back фиксируются отдельно. Целевые Windows7 SP1/8.1/10/11 x86/x64, .NET4.6.2+; полный OS/hardware matrix и физическая клавиатура не подтверждены. EXE по-прежнему без Authenticode; собственная RSA-подпись обновления не заменяет подпись издателя.

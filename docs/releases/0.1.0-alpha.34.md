# MacSwitcher 0.1.0-alpha.34 · диагностика двойного Shift

Когда MacSwitcher не может подтвердить результат замены, он сохраняет исходник и ограничивает дальнейшую запись в то же поле. В alpha.33 несколько повторных нажатий в таком поле выглядели в журнале как несколько неудачных отмен. Эти записи не означали, что жест не распознан или что текст был переписан несколько раз.

Кандидат разделяет обычную отмену и попытку восстановить поле с неподтверждённой правкой. Для распознанных приложений диагностика может называть конкретный браузер; историческая категория `browser` в alpha.33 по-прежнему означает Chrome **или** Safari. Менять задержку Shift при таком отказе не требуется. Предыдущая версия остаётся доступна в [релизе alpha.33](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.33).

Для владельца Mac, которому нужна история дольше, чем хранит системный журнал, предусмотрен отдельный локальный сборщик. Он сохраняет только разрешённые технические события: время, группу приложения, вид операции, исход и доступную причину отказа. Установка сборщика отдельная; набранные слова, адреса, названия окон и буфер обмена в историю не попадают. Архив исходников после сбоя остаётся отдельной функцией с собственным согласием и правилами доступа.

Граница проверки: диагностика помогает установить, что произошло. Она не подтверждает доставку правки во всех адресных строках и не снимает защиту с поля, пока судьба прежней записи неизвестна. Движок коррекции, назначение Shift, интервал жестов, словари и Windows в этот выпуск не входят.

Локальные проверки кандидата: 716 Swift-тестов, 0 ошибок и один условный пропуск экспорта изображений; 54 проверки Python, включая 18 проверок приватного сборщика; release-сборка прошла. Такие проверки не заменяют ручную проверку адресной строки на установленной сборке.

Первый прогон GitHub на предыдущей ревизии остановился в тесте завершения дочернего процесса. Для этого сценария время запуска тестовой среды теперь отделено от времени ожидания зависшего процесса. Проверки очистки и обычный общий дедлайн остальных сценариев сохранены. Из-за этой правки теста исходники самого приложения не менялись.

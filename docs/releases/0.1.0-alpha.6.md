# 0.1.0-alpha.6 — кандидат для приёмки

Новый native-путь подтверждает текст и каретку после каждой отправленной пары,
удерживает конкурентный ввод на отдельном event tap и отдельно подтверждает TIS.
Очень быстрый двойной Shift: до180мс между отпусканиями включительно.
Выделение заменяется одной Unicode-вставкой; одиночный Shift остаётся немедленным.

Полные точные RU/EN базы: 1178533/1387382 словоформы, по200000 пересекающихся
префиксных форм и2434 публичных термина. Источники, хеши и лицензии —
[dictionaries/NOTICE](../../dictionaries/NOTICE.md).

Проверено локально: 260 Swift-тестов,16 Python-тестов, публичный валидатор;
495 синтетических примеров (176 исправлений/319 сохранений),0 расхождений.
Это не оценка точности реального ввода. Подписанная предварительная сборка
загрузила packaged ресурсы за1,1с с пиком111МиБ в отдельном CLI-процессе.
Чистая публичная сборка и её установка фиксируются отдельно после commit.

Новый runtime ещё не принят. Обычный Codex сохраняет исключение владельца;
флаг UI-включения native_backend_accepted=false. Тестовые события адресованы
только отдельному fixturePID и проходят монитор через явный диагностический
вход. Это синтетический pipeline, не доказательство физического HID.

Ограничения:24 простых символа суффикса одинаковой длины,32768UTF-16 поле,
8192UTF-16 вставка выделения. Secure/read-only/RTL/bidi и неизвестные состояния
пропускаются. Неизвестный результат сохраняет первый полный исходник вRAM.
Штатный выход предлагает явный локальный export всех исходников в private
Recovery JSON и разрешается только после read-back; сбой процесса до экспорта
остаётся риском. Неподдерживаемый редактор не считается проверенным.

Далее: подписанная чистая установка с резервной копией, синтетические поля,
физический быстрый набор/продолжение/смена поля вTextEdit/Codex и отдельная
матрица других редакторов, одна финальная ручнаяCI и контролируемое включение.

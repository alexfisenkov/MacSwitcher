# MacSwitcher 0.1.0-alpha.16 — кандидат

> Кандидат в рабочем дереве. Публикация, подпись, нотарификация и установка
> alpha.16 не подтверждены. Исходный SHA и артефакт выпуска пока не назначены.

## Изменения кандидата

- Добавлен безопасный fallback проверки редактируемости для native-полей, где
  `AXSelectedText` нельзя записать: проверяется возможность записи `AXValue`,
  но сам текст по-прежнему передаётся клавиатурным вводом. В наблюдавшемся поле
  Telegram `AXEditable` и `AXReadOnly` отсутствовали, `AXSelectedText` был
  недоступен для записи, а `AXValue` — доступен. Явный read-only статус,
  защищённые поля и ошибки проверки продолжают блокировать правку.
- `preparationUncertain` относится к выбору/навигации до Unicode: Unicode не
  поставлен в очередь, active TEXT quarantine и recovery-исходник не создаются.
  Следующая явная попытка требует свежей проверки поля и выделения под новым input
  lease; ACK навигации этим не подтверждается. Только неизвестная доставка уже
  отправленного Unicode создаёт карантин с исходником и использует лимит в
  восемь полей.
- Новое явное подтверждённое решение раскладки может завершить прежнее ожидание
  только если наблюдаемый источник совпал с новой целью. Пассивное наблюдение
  другого источника не снимает ожидание.
- Убрано обычное уведомление о каждой коррекции. Undo двойным Shift и явное
  предложение добавить фразу в исключения сохранены. Важное уведомление и
  предложение занимают одну область справа внизу, скрывают друг друга, имеют
  кнопку закрытия. Уведомление об ошибке ограничено 30-секундным дедупом;
  предложение показывается 12 секунд и не повторяется для той же фразы в течение
  сессии. Тексты упрощены.

## Результаты целевых проверок

- Регрессии проверки редактируемости: исходно 2 отказа из 12; после исправления
  целевой набор прошёл 12/12.
- Два новых production-сценария: исходно 10 отказов из 17; после исправления
  целевой производственный набор прошёл 74/74.
- До дополнительной правки, найденной code review, локально прошли 416/416
  Swift-тестов, 25/25 Python-проверок, 495/495 примеров gold-корпуса и 17/17
  целевых проверок TIS.

Независимый code review после этих результатов выявил необходимость свежей
проверки идентичности перед отменой навигации; Sol вносит дополнительную правку.
После неё полный набор ещё не запускался, поэтому приведённые результаты не
являются итоговым PASS текущего кандидата. Они не подтверждают сборку релиза, CI,
физический ввод или поведение установленной версии.

## Открытая приёмка

В alpha.15 пользователь сообщил о периодическом отказе автоматической и ручной
правки после длительной работы, отсутствии реакции двойного Shift на выделенное
мышью предложение в Telegram и путанице из-за нескольких баннеров. Кандидат
содержит адресные изменения для этих случаев, но они не подтверждены после
публикации и установки. Требуются повторный физический ввод в нейтральном
редакторе и Telegram, повторные правки после продолжительного использования,
проверка undo и просмотр поведения уведомлений. До этого `native_backend_accepted`
не меняется.

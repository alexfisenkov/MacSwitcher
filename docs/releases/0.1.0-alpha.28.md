# MacSwitcher 0.1.0-alpha.28 — кандидат

Исправлен русский приоритет после английского названия: например, `MacSwitcher f` может стать `MacSwitcher а`, `ChatGPT ye` — `ChatGPT ну`. Само название сохраняется. Обычные английские фразы, технические подсказки и пользовательские исключения продолжают учитываться; частотные строчные омонимы не считаются названием автоматически. В существующую базу названий добавлен iPhone.

Исправлена отмена автозамены двойным Shift: сохранённое слово не меняется снова при пробеле или вводе следующего русского слова. Продолжение отменённого слова остаётся как набрано, а новое слово снова распознаётся. Уже закрытое пробелом слово не требует дополнительного пробела для возобновления. Учтены другое поле того же приложения, подтверждённая смена раскладки и временная недоступность AX; проверки записи не ослаблены.

Локально прошли 535 Swift-тестов, 35 Python-проверок и release-сборка. Подпись, итоговая CI, публикация и установленный результат фиксируются после выполнения. Это исправление подтверждённых причин пропусков, без заявления об устранении любого возможного отказа редактора.

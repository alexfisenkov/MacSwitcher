# Решение: собственные подписанные обновления

Статус: решение принято; реализация и сквозная проверка ещё не завершены.

Пользователь выбирает установку кнопкой после уведомления. Обновление должно
сохранять настройки и локальный личный словарь, а upstream-приложение не
участвует в проверке или установке.

Выбран Sparkle 2.10.0 с закреплённой зависимостью. Его опубликованная минимальная
система — macOS 12; целевая нижняя граница MacSwitcher остаётся macOS 13.
Первичные материалы: [релиз Sparkle 2.10.0](https://github.com/sparkle-project/Sparkle/releases/tag/2.10.0),
[программное подключение](https://sparkle-project.org/documentation/programmatic-setup/),
[публикация обновлений](https://sparkle-project.org/documentation/publishing/).

Альтернатива — дополнить нынешнюю проверку GitHub Releases собственным
загрузчиком и установщиком. Она требует самостоятельной реализации проверки
подлинности архива, безопасной распаковки, доверия к бандлу, замены, прав,
перезапуска и отката. Подключение поддерживаемого updater уменьшает этот объём,
но добавляет binary dependency, которую нужно правильно встроить и подписать.

Обязательные границы реализации:

- HTTPS feed принадлежит только MacSwitcher; архивы находятся в собственных
  неизменяемых GitHub Releases. Изменение настроек GitHub Pages не требуется.
- EdDSA подпись архива проверяется доверенным публичным ключом установленного
  приложения. Наличие HTTPS или SHA-256 само по себе не заменяет подпись издателя.
  Закрытый ключ остаётся вне репозитория и диагностических выводов.
- Developer ID подпись, notarization, ticket и Gatekeeper проверяются отдельно.
  Все framework/helper исполняемые компоненты должны иметь нужные arm64/x86_64
  срезы и правильную вложенную подпись.
- Фоновая проверка может сообщить об обновлении; установка требует явной кнопки.
  Автоматическая установка и system profiling отключены.
- Сохраняются отказ/отмена `applicationShouldTerminate`, восстановление исходных
  текстов и завершение владения clipboard. Отмена выхода запрещает установку.
- Ошибка загрузки, подписи или замены сохраняет прежнюю программу и данные;
  повтор не разрешается вслепую при неизвестном состоянии.

Проверяются установка подписанного обновления, отмена при pending-правке,
сохранение настроек/словаря, плохая подпись, прерванная загрузка и откат.
Нынешняя ссылка на страницу релиза остаётся временным доступным действием
до успешной интеграции. Она не считается выполнением требования установки
обновления по кнопке.

Caramba рассматривается только как пример желаемого поведения. Проверенного
официального открытого репозитория его реализации не установлено; найденный
локальный пакет не исследовался через декомпиляцию. Внутренний алгоритм ему
не приписывается. [Официальный сайт](https://caramba-switcher.com/) описывает
пользовательское поведение, а не доказывает устройство кода.

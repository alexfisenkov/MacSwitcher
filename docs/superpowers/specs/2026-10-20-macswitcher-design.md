# MacSwitcher: первая публичная версия

Владелец просит развивать переключатель для людей на собственном опыте, публиковать
весь повторно используемый код в GitHub и сохранять привычки: один любой Shift
меняет язык сразу, два исправляют последнее слово либо выделение.
Ошибка текущего решения — проверка только после пробела, пропуск коротких слов
и отсутствие истории предыдущего неоднозначного слова. Примеры: `f привет`
должно иметь возможность стать `а привет`; `levf.` — `думаю`, если хватает
уверенности; `xnj-nj nfrjt` — `что-то такое`.

Технические решения агента: отдельный SwiftPM macOS-проект на существующей
MIT-основе, собственная идентичность приложения и обновлений, ограниченный
контекст в RAM, офлайн-частоты RU/EN. Разделение engine/coordinator/executor
описано в `docs/architecture.md`. Нельзя подменять намерение простым правилом
«любая f = а», портить `f(x)`, настоящие английские слова, бренды, API и код.

Публикуются код, общие словари с лицензиями, тесты, build/release scripts и планы.
Не публикуются реальные тексты/clipboard/секреты/персональная история.
Оплата не требуется. Донаты — будущая добровольная функция после получения
подтверждённой ссылки владельца. Никакого перенаправления на чужие платежи.

Первая версия реализует локальные эвристики с ранним принятием уверенных решений
и отложенной коррекцией, а не всеобщее самообучение или LLM. Ошибочные замены
опаснее пропусков: проверенный PID/AX/suffix executor обязателен. Старый рабочий
контур сохраняется до отдельной приёмки. Полная матрица и продолжение — roadmap.

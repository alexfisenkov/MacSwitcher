# MacSwitcher

Открытый переключатель русской и английской раскладки для macOS.
Развиваем на собственном опыте и публикуем улучшения для всех.

**Первая alpha в разработке.** Автокоррекция использует локальные частоты и
короткий контекст; это не гарантия угадывания любого слова.

Проверка владельца подтвердила одиночный Shift и исправление последнего слова.
В подписанной alpha.3 проверены внутренние пути TextEdit: выделение
`ghbdtn → привет` и раннее `ghbd → прив` без пробела. Физические Shift и
другие редакторы ещё проходят приёмку. [Статус](docs/roadmap.md).

- Короткий одиночный левый или правый **Shift** сразу меняет раскладку.
- Быстрый **двойной Shift** исправляет последнее слово или выделенный текст.
- Новый обработчик проверяет уверенные ошибки во время набора, до пробела.
- Короткая неоднозначная `f` может стать `а`, когда продолжение подтверждает русский.
- 200 000 русских и 200 000 английских частотных словоформ поставляются офлайн.
- Английские слова, аббревиатуры и технические токены получают защиту.

macOS 13+, без сервера, подписки и отправки текста. Для работы нужны
Accessibility и Input Monitoring. При недоступном точном AX-поле автоматическая
правка пропускается. Совместимость с конкретными редакторами требует приёмки.
Одновременно должен работать один переключатель, иначе они конкурируют.
Автоматическое исправление включается вашим ответом при первом запуске
или галочкой в настройках; отказ сохраняется.

## Установка и обновление

Первая alpha ещё проходит приёмку. Пока готового установочного файла нет,
используйте сборку из исходников по инструкции ниже. Публичный стабильный
выпуск появится после проверки подписи, notarization и живого ввода.

Для готовой `.app`: завершите текущий переключатель через его меню, сохраните
его для отката и перенесите `MacSwitcher.app` в `~/Applications`.
Если у вас была личная сборка `com.alexfisenkov.ruswitcher.local`, **до первого
запуска** выполните описанный ниже dry-run и `script/migrate_settings.py --apply`.
Затем откройте MacSwitcher.
В Системных настройках → Конфиденциальность и безопасность выдайте **MacSwitcher**
Accessibility и Input Monitoring, затем перезапустите приложение.
Права другого переключателя не переносятся. Выберите нужные раскладки,
включите автоматическое исправление и проверьте одиночный Shift с обеих сторон,
двойной Shift на слове и выделении, обычную заглавную букву и английский текст.

Обновление: скачайте нашу новую сборку, завершите MacSwitcher и замените `.app`;
настройки хранятся отдельно. Для отката завершите MacSwitcher и верните предыдущую
сборку. Если возвращаетесь к другому переключателю, запускайте только его.

## Разработка

Нужен Swift 6 / Xcode Command Line Tools на Mac.
Для интеграционных тестов должны быть включены стандартные английская и русская
раскладки. На временном CI-runner их включает отдельная fixture; локальные тесты
сами не меняют выбранную раскладку.

```sh
swift test --package-path macos -j 4
python3 -m unittest discover -s script -p 'test_*.py' -v
python3 script/check_public.py
python3 script/build_app.py --ad-hoc
```

Результат: `.сборки/MacSwitcher.app`. При изменениях исходников добавьте
`--allow-dirty`, чтобы явно пометить экспериментальную сборку. Для сборки и
запуска используйте `./script/build_and_run.sh --ad-hoc --allow-dirty`;
он потребует сначала завершить работающий переключатель.

Ad-hoc подходит для локальной разработки. Распространяемый выпуск требует
Developer ID, notarization и отдельной Gatekeeper-проверки. Скрипты не содержат
ключей подписи. Swift-модуль пока сохраняет внутреннее имя `RuSwitcher`.

Словари уже входят в репозиторий. Повторный импорт из закреплённого источника:
`python3 script/import_dictionaries.py --download`.
Перенос прежних настроек: `python3 script/migrate_settings.py --help`;
по умолчанию просмотр, запись только с `--apply`. Права macOS не переносятся.
Этот скрипт читает только прежнюю личную сборку
`com.alexfisenkov.ruswitcher.local`, а не любой RuSwitcher. Запускайте перенос
до первого запуска MacSwitcher, пока он закрыт. Уже существующие значения
MacSwitcher сохраняются; пустой `selected_keys` означает, что добавлять нечего.
Во время `--apply` не открывайте MacSwitcher и не редактируйте его настройки
другими утилитами. Резервная копия назначения сохраняется локально.

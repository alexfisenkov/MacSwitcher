# MacSwitcher

Локальный переключатель русской и английской раскладки для macOS. Короткое одиночное нажатие Shift сразу меняет язык; двойное нажатие исправляет последнее слово или выделение. Уверенная автоматическая коррекция может срабатывать во время набора. Если MacSwitcher не может безопасно изменить текст или проверить результат, он остановится. Парольные поля приложение пропускает.

**Последний опубликованный выпуск — [alpha.14](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.14).** Текущий исходный код alpha.15 (build 15 metadata) прошёл локальные проверки: Swift 404/404, Python tooling 25/25, корпус gold 495/495 и проверка 166 публичных файлов. Alpha.15 не опубликована и не установлена; физическая проверка и матрица приложений не подтверждены. См. [план развития](docs/roadmap.md) и [спецификацию](docs/specification.md).

Приложение предназначено для macOS 13 и новее. Обработка текста и словари локальные; данные набора не отправляются в сеть. Для работы нужны разрешения Accessibility и Input Monitoring. Совместимость зависит от доступности безопасного текстового поля в конкретном приложении; поддержка всех редакторов не заявляется.

## Установка

1. Скачайте ZIP со [страницы релизов](https://github.com/alexfisenkov/MacSwitcher/releases), распакуйте его и перенесите `MacSwitcher.app` в папку «Программы».
2. Откройте приложение. Если macOS запросит доступ, разрешите его в разделах «Универсальный доступ» и «Мониторинг ввода» системных настроек.
3. Включите автокоррекцию при первом запуске или через значок MacSwitcher в строке меню.

Для обычного обновления используйте проверку обновлений в меню MacSwitcher. Идентификатор приложения и каталоги данных сохраняются, поэтому настройки и личный словарь остаются на месте. Перенос из прежней локальной сборки описан отдельно в [инструкции для сопровождающего](docs/releasing.md#legacy-local-build-migration).

# MacSwitcher

Локальный переключатель русской и английской раскладки для macOS. Короткое одиночное нажатие Shift сразу меняет язык; двойное нажатие исправляет последнее слово или выделение. Уверенная автоматическая коррекция может срабатывать во время набора. Если MacSwitcher не может безопасно изменить текст или проверить результат, он остановится. Парольные поля приложение пропускает.

**Последний выпуск — [MacSwitcher alpha.18](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.18)**, предварительная версия для macOS 13+. Исправлена проверка времени одиночного и двойного Shift. [Финальная CI](https://github.com/alexfisenkov/MacSwitcher/actions/runs/40703703898), подпись Apple, notarization, Gatekeeper, опубликованный архив и штатное обновление alpha.17 → alpha.18 проверены; все 20 контролируемых настроек сохранились при обновлении. Владелец подтвердил переключение каждым одиночным Shift, в том числе после паузы в секунду; после отдельной настройки интервала двойного нажатия на 180 мс повторные пары с естественным ритмом стали стабильными. Совместимость со всеми редакторами и длительная работа остаются открытой приёмкой. Подробности — в [заметках alpha.18](docs/releases/0.1.0-alpha.18.md).

Приложение предназначено для macOS 13 и новее. Обработка текста и словари локальные; данные набора не отправляются в сеть. Для работы нужны разрешения Accessibility и Input Monitoring. Совместимость зависит от доступности безопасного текстового поля в конкретном приложении; поддержка всех редакторов не заявляется.

## Установка

1. Скачайте ZIP со [страницы релизов](https://github.com/alexfisenkov/MacSwitcher/releases), распакуйте его и перенесите `MacSwitcher.app` в папку «Программы».
2. Откройте приложение. Если macOS запросит доступ, разрешите его в разделах «Универсальный доступ» и «Мониторинг ввода» системных настроек.
3. Включите автокоррекцию при первом запуске или через значок MacSwitcher в строке меню.

Для обычного обновления используйте проверку обновлений в меню MacSwitcher. Идентификатор приложения и каталоги данных не меняются. При проверке alpha.16 → alpha.17 все 20 контролируемых настроек сохранились; файл личного словаря отсутствовал, поэтому сохранность существующего файла в этом прогоне не проверена. Перенос из прежней локальной сборки описан отдельно в [инструкции для сопровождающего](docs/releasing.md#legacy-local-build-migration).

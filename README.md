# MacSwitcher

Локальный переключатель русской и английской раскладки для macOS и Windows. Короткое одиночное нажатие Shift сразу меняет язык; двойное нажатие исправляет последнее слово или выделение. Уверенная автоматическая коррекция может срабатывать во время набора. Если MacSwitcher не может безопасно изменить текст или проверить результат, он остановится. Парольные поля приложение пропускает.

**Последний macOS-выпуск — [alpha.30](https://github.com/alexfisenkov/MacSwitcher/releases/tag/v0.1.0-alpha.30)**: исправлено освобождение защитного буфера после неподтверждённых замен, добавлено добровольное локальное сохранение исходников после сбоя. Такая копия может содержать весь текст поля; настройка по умолчанию выключена. [CI](https://github.com/alexfisenkov/MacSwitcher/actions/runs/42656185041) прошёл: 557 Swift-тестов, 35 Python-проверок, 495/495 языковых примеров. Universal-пакет подписан Developer ID, принят Apple и проверен Gatekeeper. [Заметки](docs/releases/0.1.0-alpha.30.md), [контракт исправления](docs/plans/2026-11-09-recovery-capacity.md). Физическая приёмка повторных жестов ещё ожидается; Spotlight/Campo и Terminal остаются отдельными открытыми случаями.

Версия для macOS предназначена для macOS 13 и новее. Обработка текста и словари локальные; данные набора не отправляются в сеть. На Mac для работы нужны разрешения Accessibility и Input Monitoring. Совместимость зависит от доступности безопасного текстового поля в конкретном приложении; поддержка всех редакторов не заявляется.

## Установка

1. Скачайте ZIP со [страницы релизов](https://github.com/alexfisenkov/MacSwitcher/releases), распакуйте его и перенесите `MacSwitcher.app` в папку «Программы».
2. Откройте приложение. Если macOS запросит доступ, разрешите его в разделах «Универсальный доступ» и «Мониторинг ввода» системных настроек.
3. Включите автокоррекцию при первом запуске или через значок MacSwitcher в строке меню.

Для обычного обновления используйте проверку обновлений в меню MacSwitcher. Идентификатор приложения и каталоги данных не меняются. При проверке alpha.16 → alpha.17 все 20 контролируемых настроек сохранились; файл личного словаря отсутствовал, поэтому сохранность существующего файла в этом прогоне не проверена. Перенос из прежней локальной сборки описан отдельно в [инструкции для сопровождающего](docs/releasing.md#legacy-local-build-migration).

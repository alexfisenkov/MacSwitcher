# MacSwitcher

Открытый переключатель русской и английской раскладки для macOS.
Развиваем на собственном опыте и публикуем улучшения для всех.

**Alpha.7 готовится к приёмке после отказа alpha.6.** Автокоррекция использует локальные частоты и
короткий контекст; это не гарантия угадывания любого слова. Обычный режим Codex
пока выключен до проверки нового обработчика. [Текущий статус](docs/roadmap.md).

- Короткий одиночный левый или правый **Shift** сразу меняет раскладку.
- **Очень быстрый двойной Shift** исправляет последнее слово или выделенный текст:
  между отпусканиями клавиши должно пройти не больше 180 мс. Более длинная пауза
  означает два отдельных переключения языка. Shift+буква остаётся обычным вводом.
- Уверенные ошибки проверяются во время набора, до пробела; неоднозначные ждут
  продолжения. Короткая `f` может стать `а`, когда контекст подтверждает русский.
- Офлайн-база содержит 1 178 533 русские и 1 387 382 английские словоформы.
  По 200 000 частых форм каждого языка участвуют в префиксной оценке;
  остальные доступны для точного поиска. Эти наборы пересекаются.
- Отдельная публичная подборка из 2 434 терминов защищает известные бренды,
  имена, технологии и другие написания; также защищаются аббревиатуры и
  технические токены. Список не охватывает все названия.

Исторически владелец подтвердил жесты и раннюю коррекцию в TextEdit. В alpha.5
одна физическая проверка в Codex подтвердила `ghbd → прив` и русскую раскладку.
Это результат прежней сборки, а не приёмка нового обработчика.
Быстрый набор, продолжение слова и переход между полями ещё нужно проверить.

macOS 13+, без сервера, подписки и отправки текста. Для работы нужны
Accessibility и Input Monitoring. Парольные и неподдерживаемые поля пропускаются;
совместимость с конкретными редакторами требует приёмки. Одновременно должен
работать один переключатель, иначе они конкурируют.
Автоматическое исправление включается вашим ответом при первом запуске
или галочкой в настройках; отказ сохраняется. Существующие настройки и исключения
приложений не сбрасываются при обновлении.
При переходе с alpha.5 новый обработчик включается отдельным шагом приёмки.
Если прежняя автокоррекция уже отмечена галочкой, после приёмки и установки одобренного выпуска выключите
и снова включите её: это переводит установку на новый обработчик. Сохранённое
исключение приложения нужно отдельно убрать в настройках, чтобы разрешить
автокоррекцию в нём. Владелец тестовой установки получает этот переход после
проверки кандидата; наличие старой галочки само по себе его не подтверждает. Непринятый кандидат
не включает новый обычный путь повторным нажатием галочки.

## Установка и обновление

Кандидат alpha.7 ещё проходит приёмку. Сборка из исходников описана ниже.
Стабильный выпуск требует проверки подписи, notarization и живого ввода;
сборка и синтетические тесты сами по себе этого не подтверждают.

Для готовой `.app`: завершите текущий переключатель через его меню, сохраните
его для отката и перенесите `MacSwitcher.app` в `~/Applications`.
Если у вас была личная сборка `com.alexfisenkov.ruswitcher.local`, **до первого
запуска** выполните описанный ниже dry-run и `script/migrate_settings.py --apply`.
Затем откройте MacSwitcher.
В Системных настройках → Конфиденциальность и безопасность выдайте **MacSwitcher**
Accessibility и Input Monitoring, затем перезапустите приложение.
Права другого переключателя не переносятся. Выберите нужные раскладки,
включите автоматическое исправление и проверьте одиночный Shift с обеих сторон,
двойной Shift на слове и выделении, обычную заглавную букву и английский текст.

Обновление: скачайте нашу новую сборку, завершите MacSwitcher и замените `.app`;
настройки хранятся отдельно. Для отката завершите MacSwitcher и верните предыдущую
сборку. Если возвращаетесь к другому переключателю, запускайте только его.

## Разработка

Нужен Swift 6 / Xcode Command Line Tools на Mac.
Для интеграционных тестов должны быть включены стандартные английская и русская
раскладки. На временном CI-runner их включает отдельная fixture; локальные тесты
сами не меняют выбранную раскладку.

```sh
swift test --package-path macos -j 4
python3 -m unittest discover -s script -p 'test_*.py' -v
python3 script/check_public.py
python3 script/build_app.py --ad-hoc
```

Результат: `.сборки/MacSwitcher.app`. Проверка ресурсов и публичного
синтетического корпуса в собранном приложении:

```sh
.сборки/MacSwitcher.app/Contents/MacOS/RuSwitcher --self-test-resources
.сборки/MacSwitcher.app/Contents/MacOS/RuSwitcher --benchmark-prediction
```

Корпус содержит 495 заранее размеченных примеров (gold revision 2). Отчёт
показывает пропуски, ложные и неверные замены и время оценки; он не измеряет
точность на произвольном реальном наборе или доставку событий редактору.

При изменениях исходников добавьте
`--allow-dirty`, чтобы явно пометить экспериментальную сборку. Для сборки и
запуска используйте `./script/build_and_run.sh --ad-hoc --allow-dirty`;
он потребует сначала завершить работающий переключатель.

Ad-hoc подходит для локальной разработки. Распространяемый выпуск требует
Developer ID, notarization и отдельной Gatekeeper-проверки. Скрипты не содержат
ключей подписи. Swift-модуль пока сохраняет внутреннее имя `RuSwitcher`.

Словари уже входят в репозиторий. Повторный импорт из закреплённого источника:
`python3 script/import_dictionaries.py --download`.
Перенос прежних настроек: `python3 script/migrate_settings.py --help`;
по умолчанию просмотр, запись только с `--apply`. Права macOS не переносятся.
Этот скрипт читает только прежнюю личную сборку
`com.alexfisenkov.ruswitcher.local`, а не любой RuSwitcher. Запускайте перенос
до первого запуска MacSwitcher, пока он закрыт. Уже существующие значения
MacSwitcher сохраняются; пустой `selected_keys` означает, что добавлять нечего.
Во время `--apply` не открывайте MacSwitcher и не редактируйте его настройки
другими утилитами. Резервная копия назначения сохраняется локально.

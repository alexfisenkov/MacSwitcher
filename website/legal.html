Конфиденциальность

MacSwitcher выполняет коррекцию текста на устройстве. Приложение не отправляет набранный текст, содержимое выделения или личный словарь на сервер проекта. Защищённые поля паролей пропускаются.

Для взаимодействия с клавиатурой и активным текстовым полем macOS запрашивает системные разрешения «Универсальный доступ» и «Мониторинг ввода». Разрешения обрабатываются настройками macOS и могут быть отозваны пользователем.

Этот статический сайт не использует аналитику, рекламные трекеры, формы или cookies. При переходе к загрузке GitHub может обрабатывать сетевые данные по своей политике конфиденциальности.

Условия использования

MacSwitcher распространяется как предварительная alpha-версия. Поведение зависит от приложения, конкретного текстового поля и системных разрешений; совместимость со всеми приложениями не гарантируется.

Исходный код приложения распространяется по лицензии MIT. Уведомления об авторстве и происхождении кода приведены в NOTICE.md. Словарные данные имеют отдельные условия лицензирования, указанные в dictionaries/NOTICE.md.
